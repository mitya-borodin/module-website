## Принцип документации

Каждая будущая страница должна отвечать на четыре вопроса:

1. Что получает человек?
2. Как это работает?
3. Какие есть ограничения и ручной способ управления?
4. Как проверить результат?

Пока на вопрос нет подтверждённого ответа, страница не будет изображать готовую функцию.
