## Как сочетать сценарии

Начните с одного базового поведения. Затем добавляйте по одному условию и проверяйте общий результат. Например:

1. Свет включается по движению.
2. Добавляем освещённость — включается только в темноте.
3. Добавляем шум — выключение может ждать дольше.
4. Добавляем ручную кнопку и паузу — после ручного выключения движение не включает свет обратно сразу.

Каждое добавление меняет поведение, а не только расширяет список устройств. Датчик освещённости может разрешать и выключение. Датчик движения в сценарии подсветки территории превращает включение от одной темноты во включение при активности в темноте.

### Не все сочетания совместимы

- Режим «включать только кнопкой» запрещает автоматическое включение. Период «включать по движению с 18 до 6» не отменит этот запрет.
- Шум не может стать самостоятельной причиной включения.
- Временная пауза после ручного действия не отключает все способы управления светом.
- Два независимых макроса на одном выходе не складывают свои решения в общее правило. Они могут конфликтовать.

<details>
<summary>Что здесь означает сочетание нескольких макросов</summary>

Каждая автоматизация управляет своей группой света. Они могут использовать один датчик или работать на одном объекте независимо. Это повторное использование готовой логики с разными настройками, а не передача команды между макросами разных типов.

</details>

## Перед использованием на объекте

Проверьте обычную работу, ручное действие, отсутствие реакции при запрещающих условиях и поведение соседних групп. Если показания недоступны или устройства не выполняют команды, сначала устраните эту причину — увеличение задержек не заменяет проверку связи.

Для назначения устройств откройте [первую настройку](/ru/docs/automations/lighting/setup/), для точного смысла параметров — [справочник](/ru/docs/automations/lighting/settings/).
