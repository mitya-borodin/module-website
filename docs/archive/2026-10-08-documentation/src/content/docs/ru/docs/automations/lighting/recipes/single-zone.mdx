Выберите нужный результат. Каждый рецепт ниже содержит свой список устройств и значения — проходить предыдущие примеры не нужно. Для групп с разным временем выключения откройте [несколько зон](/ru/docs/automations/lighting/recipes/several-zones/).

## Общая подготовка

Создавайте новую автоматизацию «Освещение», а не сбрасывайте уже работающую. Если делаете это впервые, откройте [пошаговую настройку](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). Все необходимые значения повторены в каждом рецепте.

Подключение электрической части должен проверить специалист. Сначала убедитесь, что нужный свет управляется из Module, а показания датчиков меняются.

## Движение без учёта освещённости

**Что получите.** Свет в проходе включается при движении в любое время суток и гаснет после ухода.

**Что понадобится.** Группа света и один датчик движения. Для примера нужен датчик со значениями 0 без движения и 100 при движении. Датчик освещённости, шум, активность оборудования и кнопки не выбирайте.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). В разделе «Входы» нажмите «+» в карточке «Дискретные выходы освещения» и выберите свою группу. Через «Входы» вернитесь к карточкам и так же выберите только перечисленные выше датчики и кнопки. После выбора сохраняйте изменения.

| Настройка | Значение |
| --- | --- |
| Автоматическое включение | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | 00:00 и 00:00 — круглосуточно |
| Агрегация движения | Максимальное значение — реагировать на любой выбранный датчик |
| Порог движения | 100 для датчика со шкалой 0/100 |
| Ожидание полной тишины | 2 мин |
| Ожидание без движения при шуме | 0 мин |
| Блокировка автоматического включения | 0 мин |
| Блокировка автоматического выключения | 0 мин |
| Включение и выключение по времени | Не заданы |

«Сначала включить всю группу» оставьте выключенным. На первом экране в «Условные настройки» не добавляйте правила. Сохраните изменения разделов, проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена». Нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана».

**Как проверить.**

1. Пройдите перед датчиком — свет должен загореться, даже если в помещении светло.
2. Продолжайте двигаться — свет остаётся включённым.
3. Выйдите из зоны. После двух минут без движения дождитесь выключения; оно может произойти немного позже двухминутной отметки.

**Важно.** Неподвижного человека датчик может не замечать. Для другой шкалы движения подберите допустимый порог; датчик 0/1 для этого примера не подходит.

<details>
<summary>От какого события считаются две минуты</summary>

От последней обнаруженной активности, а не от включения лампы. Новая активность начинает ожидание заново; для выключения должно пройти больше заданного срока.

</details>

## Движение в темноте

**Что получите.** При движении свет включается только тогда, когда естественного освещения недостаточно.

**Что понадобится.** Группа света, датчик движения со шкалой 0/100 и датчик освещённости в люксах. Шум, активность оборудования и кнопки не выбирайте.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). В разделе «Входы» нажмите «+» в карточке «Дискретные выходы освещения» и выберите свою группу. Через «Входы» вернитесь к карточкам и так же выберите только перечисленные выше датчики и кнопки. После выбора сохраняйте изменения.

| Настройка | Значение |
| --- | --- |
| Автоматическое включение | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | 00:00 и 00:00 — круглосуточно |
| Агрегация движения | Максимальное значение — реагировать на любой выбранный датчик |
| Порог движения | 100 для датчика со шкалой 0/100 |
| Агрегация освещённости | Максимальное значение |
| Порог включения по освещённости | 25 lx |
| Порог выключения по освещённости | 500 lx |
| Ожидание полной тишины | 2 мин |
| Ожидание без движения при шуме | 0 мин |
| Блокировка автоматического включения | 0 мин |
| Блокировка автоматического выключения | 0 мин |
| Включение и выключение по времени | Не заданы |

«Сначала включить всю группу» оставьте выключенным. На первом экране в «Условные настройки» не добавляйте правила. Сохраните изменения разделов, проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена». Нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана».

**Как проверить.**

1. При освещённости 25 lx или ниже пройдите перед датчиком — свет должен включиться.
2. При освещённости выше 25 lx погашенный свет не должен включаться от движения.
3. Выйдите из зоны и дождитесь выключения после двух минут без движения; возможна небольшая задержка.
4. Проверьте и дневной свет: при 500 lx и выше освещение может погаснуть, даже если движение продолжается.

**Важно.** Подберите оба порога по месту. Свет от самих ламп не должен достигать порога выключения на датчике. Для другой шкалы движения нужен подходящий порог; 0/1 для примера не подходит.

<details>
<summary>Почему нужны два порога освещённости</summary>

Нижняя граница разрешает включение, верхняя — выключение. Между ними одно изменение освещённости не должно вызывать переключение. Это помогает избежать частого включения и выключения около одной границы.

</details>

## Два датчика в одном проходе

**Что получите.** Один и тот же свет включается, с какой бы стороны прохода вы ни подошли.

**Что понадобится.** Группа света и два датчика движения с одинаковой шкалой 0/100. Оба выберите в «Датчиках движения». Освещённость, шум, активность оборудования и кнопки не выбирайте.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). После выбора сохраняйте изменения.

| Агрегация движения | Максимальное значение — реагировать на любой выбранный датчик |

**Как проверить.**

1. Пройдите перед первым датчиком, затем отдельно перед вторым — каждый должен включать свет.
2. Пока хотя бы один датчик видит движение, свет остаётся включённым.
3. Выйдите из обеих зон и дождитесь выключения после двух минут без движения, с возможной небольшой задержкой.

**Важно.** Это одна группа света, а не последовательное включение участков или ступеней. У датчиков должны быть сопоставимые шкалы. Для шкалы, отличной от 0/100, подберите общий допустимый порог; 0/1 не подходит.

<details>
<summary>Как MAX объединяет два датчика</summary>

Module сравнивает порог с наибольшим из доступных показаний. Поэтому для двух одинаковых датчиков достаточно активности любого; чтобы закончить ожидание, движение должно прекратиться у обоих.

</details>

## Включение кнопкой, выключение после ухода

**Что получите.** Вы включаете свет кнопкой. После ухода он гаснет сам, даже если вы забыли его выключить.

**Что понадобится.** Группа света, датчик движения со шкалой 0/100 и кнопка или выключатель. Освещённость, шум и активность оборудования не выбирайте. Для переключателя выберите срабатывающий уровень по его подключению.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). В разделе «Входы» нажмите «+» в карточке «Дискретные выходы освещения» и выберите свою группу. Через «Входы» вернитесь к карточкам и так же выберите только перечисленные выше датчики и кнопки. После выбора сохраняйте изменения.

| Настройка | Значение |
| --- | --- |
| Автоматическое включение | Выключено |
| Агрегация движения | Максимальное значение — реагировать на любой выбранный датчик |
| Порог движения | 100 для датчика со шкалой 0/100 |
| Только включение — у кнопки или переключателя | Выключено |
| Не обновлять блокировки — у кнопки или переключателя | Выключено |
| Ожидание полной тишины | 3 мин |
| Ожидание без движения при шуме | 0 мин |
| Блокировка автоматического включения | 0 мин |
| Блокировка автоматического выключения | 3 мин |
| Включение и выключение по времени | Не заданы |

«Сначала включить всю группу» оставьте выключенным. На первом экране в «Условные настройки» не добавляйте правила. Сохраните изменения разделов, проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена». Нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана».

**Как проверить.**

1. Пройдите перед датчиком при погашенном свете — движение не должно его включать.
2. Нажмите кнопку — свет включится. Повторное обычное нажатие выключит его.
3. Снова включите кнопкой и выйдите. Первые три минуты свет не должен гаснуть от датчиков. Затем дождитесь выключения после более трёх минут без движения.

**Важно.** «Только включение» оставьте выключенным: иначе такая кнопка требует разрешённого автовключения и не подходит для этого сценария. Для другой шкалы движения подберите порог; датчик 0/1 не подходит.

<details>
<summary>Зачем нужна пауза после ручного включения</summary>

Ожидание связано с последней активностью. Если датчик давно не видел движения, одна кнопка могла бы включить свет незадолго до автоматического выключения. Трёхминутная пауза сохраняет ручной выбор на этот срок.

</details>

## Учёт шума

**Что получите.** Когда движение прекратилось, но звуки продолжаются, свет горит дольше. При этом постоянный фоновый шум не оставляет его включённым бесконечно.

**Что понадобится.** Группа света, датчик движения со шкалой 0/100 и датчик шума. Освещённость, активность оборудования и кнопки в этом примере не выбирайте.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). В разделе «Входы» нажмите «+» в карточке «Дискретные выходы освещения» и выберите свою группу. Через «Входы» вернитесь к карточкам и так же выберите только перечисленные выше датчики и кнопки. После выбора сохраняйте изменения.

| Настройка | Значение |
| --- | --- |
| Автоматическое включение | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | 00:00 и 00:00 — круглосуточно |
| Агрегация движения | Максимальное значение — реагировать на любой выбранный датчик |
| Порог движения | 100 для датчика со шкалой 0/100 |
| Агрегация шума | Максимальное значение |
| Порог шума | Выше показания в тишине, но не выше показания при нужной звуковой активности |
| Ожидание полной тишины | 1 мин |
| Ожидание без движения при шуме | 10 мин |
| Блокировка автоматического включения | 0 мин |
| Блокировка автоматического выключения | 0 мин |
| Включение и выключение по времени | Не заданы |

«Сначала включить всю группу» оставьте выключенным. На первом экране в «Условные настройки» не добавляйте правила. Сохраните изменения разделов, проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена». Нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана».

**Как проверить.**

1. Включите свет движением.
2. Прекратите движение, сохраняя шум выше выбранного порога: свет не должен гаснуть через одну минуту только из-за отсутствия движения.
3. Прекратите и шум. После одной минуты без движения и шума дождитесь выключения, с возможной небольшой задержкой.
4. Повторите опыт с продолжающимся шумом. После более 11 минут без движения свет должен погаснуть и при этом фоне.

**Важно.** Шум не включает погашенный свет. Здесь 11 минут получаются из 1 минуты основного ожидания и 10 дополнительных. Если шум прекратился, свет погаснет раньше. Для другой шкалы движения нужен подходящий порог; 0/1 не подходит.

<details>
<summary>Что изменится при добавлении других датчиков</summary>

Освещённость может выключить свет раньше при достижении верхнего порога. Если выбрать активность оборудования, для выключения она должна отсутствовать дольше основного ожидания. Поэтому добавление этих датчиков требует повторной проверки всего сценария.

</details>

## Ручной выбор

**Что получите.** После ручного выключения движение не включает свет обратно 15 минут. После ручного включения датчики не гасят его минимум 30 минут.

**Что понадобится.** Группа света, датчик движения со шкалой 0/100 и кнопка или выключатель. Освещённость, шум и активность оборудования не выбирайте. Для переключателя выберите срабатывающий уровень по подключению.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). В разделе «Входы» нажмите «+» в карточке «Дискретные выходы освещения» и выберите свою группу. Через «Входы» вернитесь к карточкам и так же выберите только перечисленные выше датчики и кнопки. После выбора сохраняйте изменения.

| Настройка | Значение |
| --- | --- |
| Автоматическое включение | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | 00:00 и 00:00 — круглосуточно |
| Агрегация движения | Максимальное значение — реагировать на любой выбранный датчик |
| Порог движения | 100 для датчика со шкалой 0/100 |
| Только включение — у кнопки или переключателя | Выключено |
| Не обновлять блокировки — у кнопки или переключателя | Выключено |
| Ожидание полной тишины | 2 мин |
| Ожидание без движения при шуме | 0 мин |
| Блокировка автоматического включения | 15 мин |
| Блокировка автоматического выключения | 30 мин |
| Включение и выключение по времени | Не заданы |

«Сначала включить всю группу» оставьте выключенным. На первом экране в «Условные настройки» не добавляйте правила. Сохраните изменения разделов, проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена». Нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана».

**Как проверить.**

1. Включите свет движением, затем выключите кнопкой. В течение 15 минут движение не должно включать его обратно.
2. После окончания паузы движение снова должно включать свет.
3. Включите свет кнопкой и прекратите движение. Первые 30 минут свет должен оставаться включённым.
4. Попробуйте выключить его кнопкой до конца этих 30 минут — ручное управление остаётся доступным.

**Важно.** Паузы не запрещают нажимать кнопку. Новая пауза начинается после ручного изменения состояния, а не от любого повторного события. Для другой шкалы движения подберите порог; 0/1 не подходит.

<details>
<summary>Чем отличаются две блокировки</summary>

Пауза автоматического включения сохраняет ручной выбор «выключено». Пауза автоматического выключения сохраняет «включено». Это независимые сроки; «Не обновлять блокировки» пропускает назначение новых сроков, но не отменяет уже действующие.

</details>

## Свет при работе оборудования

**Что получите.** Рабочая зона освещается, когда оборудование начинает работать, и гаснет после завершения работы.

**Что понадобится.** Группа света и датчик потребляемой мощности в «Числовых датчиках активности». Движение, шум, освещённость и кнопки не выбирайте.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). В разделе «Входы» нажмите «+» в карточке «Дискретные выходы освещения» и выберите свою группу. Через «Входы» вернитесь к карточкам и так же выберите только перечисленные выше датчики и кнопки. После выбора сохраняйте изменения.

| Настройка | Значение |
| --- | --- |
| Автоматическое включение | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | 00:00 и 00:00 — круглосуточно |
| Агрегация числовой активности | Максимальное значение |
| Порог числовой активности | Например, 20 — только для измерения в ваттах, если это число отделяет работу от ожидания |
| Ожидание полной тишины | 2 мин |
| Ожидание без движения при шуме | 0 мин |
| Блокировка автоматического включения | 0 мин |
| Блокировка автоматического выключения | 0 мин |
| Включение и выключение по времени | Не заданы |

«Сначала включить всю группу» оставьте выключенным. На первом экране в «Условные настройки» не добавляйте правила. Сохраните изменения разделов, проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена». Нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана».

**Как проверить.**

1. При мощности ниже выбранного порога погашенный свет не должен включаться от этого датчика.
2. Запустите оборудование обычным безопасным способом. При достижении порога свет должен включиться.
3. Остановите оборудование. Когда показание остаётся ниже порога больше двух минут, дождитесь выключения света.

**Важно.** Порог подбирается по реальным показаниям и должен быть положительным. Сценарий управляет только светом, а не оборудованием или его защитой.

<details>
<summary>Что будет, если добавить датчик движения</summary>

Свет сможет включаться по движению или работе оборудования. Эти два признака не образуют требование «оба одновременно». Не объединяйте несопоставимые измерения: ватты и амперы автоматически не пересчитываются.

</details>

## Подсветка территории

**Что получите.** Подсветка включается с наступлением темноты и гаснет, когда естественного света достаточно. Движение для этого не требуется.

**Что понадобится.** Группа наружного света и датчик освещённости в люксах. Движение, шум, активность оборудования и кнопки не выбирайте.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). В разделе «Входы» нажмите «+» в карточке «Дискретные выходы освещения» и выберите свою группу. Через «Входы» вернитесь к карточкам и так же выберите только перечисленные выше датчики и кнопки. После выбора сохраняйте изменения.

| Настройка | Значение |
| --- | --- |
| Автоматическое включение | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | 00:00 и 00:00 — круглосуточно |
| Агрегация освещённости | Максимальное значение |
| Порог включения по освещённости | 25 lx — подберите по месту |
| Порог выключения по освещённости | 500 lx — подберите по месту |
| Ожидание полной тишины | 0 мин — выключение по отсутствию активности отключено |
| Ожидание без движения при шуме | 0 мин |
| Блокировка автоматического включения | 0 мин |
| Блокировка автоматического выключения | 0 мин |
| Включение и выключение по времени | Не заданы |

«Сначала включить всю группу» оставьте выключенным. На первом экране в «Условные настройки» не добавляйте правила. Сохраните изменения разделов, проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена». Нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана».

**Как проверить.**

1. При снижении освещённости до 25 lx или ниже свет должен включиться без движения.
2. При достижении 500 lx и выше он должен выключиться.
3. Между порогами убедитесь, что небольшие изменения освещённости не вызывают постоянных переключений.

**Важно.** Датчик не должен чрезмерно освещаться самой подсветкой. Если добавить движение или активность оборудования, одной темноты уже будет недостаточно для включения.

<details>
<summary>Почему ожидания активности равны нулю</summary>

В этом сценарии включение и выключение зависят от освещённости. Задержки после движения или шума не нужны: эти датчики не выбраны. Ноль отключает соответствующее условие ожидания.

</details>

## Включение только вечером и ночью

**Что получите.** Свет реагирует на движение с 18:00 до 06:00. Днём движение не включает его.

**Что понадобится.** Группа света и датчик движения со шкалой 0/100. Освещённость, шум, активность оборудования и кнопки в этом примере не выбирайте.

**Как настроить.** [Создайте новую автоматизацию «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). В разделе «Входы» нажмите «+» в карточке «Дискретные выходы освещения» и выберите свою группу. Через «Входы» вернитесь к карточкам и так же выберите только перечисленные выше датчики и кнопки. После выбора сохраняйте изменения.

| Настройка | Значение |
| --- | --- |
| Автоматическое включение | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | Начало — 18:00, конец — 06:00; по времени установки |
| Агрегация движения | Максимальное значение — реагировать на любой выбранный датчик |
| Порог движения | 100 для датчика со шкалой 0/100 |
| Ожидание полной тишины | 2 мин |
| Ожидание без движения при шуме | 0 мин |
| Блокировка автоматического включения | 0 мин |
| Блокировка автоматического выключения | 0 мин |
| Включение и выключение по времени | Не заданы |

«Сначала включить всю группу» оставьте выключенным. На первом экране в «Условные настройки» не добавляйте правила. Сохраните изменения разделов, проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена». Нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана».

**Как проверить.**

1. Вечером после 18:00 пройдите перед датчиком — свет должен включиться.
2. Выйдите и дождитесь выключения после двух минут без движения, с возможной небольшой задержкой.
3. Днём после 06:00 движение не должно включать погашенный свет.
4. Проверьте работу до и после полуночи: она не должна прерывать ночной период.

**Важно.** В 06:00 уже горящий свет не гаснет только из-за окончания периода: он выключается после отсутствия движения. Для другой шкалы движения подберите порог; 0/1 не подходит.

<details>
<summary>Чем период отличается от команды по времени</summary>

Период только разрешает новые включения от датчиков. Он не назначает команды «включить в 18:00» или «выключить в 06:00». Поэтому отдельные действия по времени в этом рецепте оставлены незаданными.

</details>

## Если сценарий работает иначе

Откройте [проверку по признаку проблемы](/ru/docs/automations/lighting/diagnostics/). Сверьте выбранные устройства и значения с таблицей именно вашего сценария. После исправления повторите действия, при которых свет должен включаться, и те, при которых должен оставаться погашенным.
