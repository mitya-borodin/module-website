title: Несколько групп и макросов
description: Настройте разные правила для помещений или один датчик для двух групп с разными задержками.
---

Для каждой группы света можно создать свою автоматизацию «Освещение». Например, проход гаснет быстро, рабочая зона — позже, а территория освещается с наступлением темноты.

Каждый пример ниже можно настроить отдельно. Подключение электрической части должен проверить специалист; перед настройкой убедитесь, что свет управляется из Module и датчики передают показания.

## У каждой зоны своё поведение

**Что получите.** Свет в проходе выключается после минуты без движения, на рабочем месте — после пяти минут. Наружная подсветка включается в темноте и гаснет днём.

### Что понадобится

- Три отдельные группы света: проход, рабочая зона и территория.
- Два датчика движения со шкалой 0/100: по одному для прохода и рабочей зоны.
- Датчик освещённости для наружной подсветки, передающий люксы.

Если шкала движения другая, подберите порог по ней. Допустимы целые значения от 30 до 10000; датчики 0/1 для этого примера не подходят.

### Как настроить

[Создайте три новые автоматизации «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства), назвав их «Проход», «Рабочая зона» и «Территория». В каждой выбирайте только светильники своей группы.

| Что выбрать или настроить | Проход | Рабочая зона | Территория |
| --- | --- | --- | --- |
| Дискретные выходы освещения | Свет прохода | Свет рабочей зоны | Наружная подсветка |
| Датчики движения | Датчик прохода | Датчик рабочей зоны | Не выбраны |
| Датчики освещённости | Не выбраны | Не выбраны | Наружный датчик |
| Автоматическое включение | Включено | Включено | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | 00:00 и 00:00 | 00:00 и 00:00 | 00:00 и 00:00 |
| Агрегация движения | Максимальное значение | Максимальное значение | Не используется |
| Порог движения | 100 для шкалы 0/100 | 100 для шкалы 0/100 | Не используется |
| Агрегация освещённости | Не используется | Не используется | Максимальное значение |
| Порог включения по освещённости | Не используется | Не используется | 25 lx |
| Порог выключения по освещённости | Не используется | Не используется | 500 lx |
| Ожидание полной тишины | 1 мин | 5 мин | 0 мин |
| Ожидание без движения при шуме | 0 мин | 0 мин | 0 мин |
| Обе блокировки автоматики | 0 мин | 0 мин | 0 мин |
| Включение и выключение по времени | Не заданы | Не заданы | Не заданы |

У всех трёх оставьте остальные датчики и кнопки невыбранными, раздел «Условные настройки» — без правил, «Сначала включить всю группу» — выключенным.

Подтвердите изменения разделов кнопкой «Сохранить». У каждой автоматизации проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена», затем нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана». Значения 00:00 и 00:00 разрешают включение круглосуточно.

### Как проверить

1. Пройдите только через проход — должен загореться его свет, но не рабочая зона.
2. Пройдите в рабочую зону — её свет должен включиться от своего датчика.
3. Выйдите из обеих зон. Свет прохода погаснет после одной минуты без движения, рабочей зоны — после пяти. Возможна небольшая задержка относительно этих отметок.
4. Проверьте наружную подсветку: при 25 lx и ниже она должна включиться без движения, при 500 lx и выше — выключиться.
5. Повторите движение одновременно в двух зонах: каждая должна работать по своим настройкам.

Подберите пороги наружного датчика по месту. Свет от самой подсветки не должен сразу достигать порога выключения.

<details>
<summary>Как несколько автоматизаций работают на одном объекте</summary>

Каждая получает свои показания и принимает своё решение. Одна не передаёт команду другой. Разные задержки задаются повторным использованием одного типа макроса с другими устройствами и настройками.

</details>

## Один датчик и две группы

**Что получите.** При движении включаются основной свет и подсветка. После ухода основной свет гаснет после одной минуты без движения, подсветка — после пяти.

### Что понадобится

- Две группы света, которыми можно управлять отдельно.
- Один датчик движения со шкалой 0/100.

Если датчик использует другую шкалу, подберите допустимый порог от 30 до 10000. Вариант 0/1 для этого примера не подходит.

### Как настроить

[Создайте две новые автоматизации «Освещение»](/ru/docs/automations/lighting/setup/#2-выберите-автоматизацию-и-устройства). Назовите их «Основной свет» и «Подсветка».

| Настройка | Основной свет | Подсветка |
| --- | --- | --- |
| Дискретные выходы освещения | Только основная группа | Только подсветка |
| Датчики движения | Общий датчик | Тот же датчик |
| Автоматическое включение | Включено | Включено |
| «Начало периода autoOn» и «Конец периода autoOn» | 00:00 и 00:00 — круглосуточно | 00:00 и 00:00 — круглосуточно |
| Агрегация движения | Максимальное значение | Максимальное значение |
| Порог движения | 100 для шкалы 0/100 | 100 для шкалы 0/100 |
| Ожидание полной тишины | 1 мин | 5 мин |
| Ожидание без движения при шуме | 0 мин | 0 мин |
| Обе блокировки автоматики | 0 мин | 0 мин |
| Включение и выключение по времени | Не заданы | Не заданы |

У обеих не выбирайте другие датчики и кнопки, не добавляйте правила в «Условные настройки». Оставьте «Сначала включить всю группу» выключенным.

Подтвердите изменения разделов кнопкой «Сохранить». У каждой автоматизации проверьте заполнение «Имя» и «Описание», установите «Состояние» — «Включена», затем нажмите «Создать автоматизацию» и дождитесь «Автоматизация создана». Проверьте, что общий датчик выбран в обеих, а светильники не повторяются.

### Как проверить

1. Пройдите перед датчиком — обе группы должны загореться.
2. Выйдите из зоны. Дождитесь выключения основного света после одной минуты без движения, подсветки — после пяти. Возможна небольшая задержка.
3. Пройдите снова, пока подсветка ещё горит: основной свет должен включиться, а ожидание подсветки — начаться заново.

<details>
<summary>Почему один датчик может использоваться в двух автоматизациях</summary>

Обе получают общие показания, но отдельно считают время и управляют разными светильниками. Это не команда одного макроса другому. Совпадение физического момента включения до миллисекунды не гарантируется.

</details>

## Почему нельзя просто дать двум макросам одну лампу

**Одним светильником должна управлять одна ответственная автоматизация.** Иначе одна может включать его, а другая — сразу выключать.

Для реакции на несколько датчиков выберите их в одной автоматизации. Для разных задержек разделите сами группы света.

<details>
<summary>Откуда берётся конфликт команд</summary>

Макрос может повторять своё целевое состояние, когда обнаруживает другое значение у управляемого выхода. Два макроса не объединяют свои решения автоматически: если их цели различаются, устройство получает противоречащие команды.

Общий датчик передаёт информацию обоим макросам. Общий управляемый выход требует отдельного согласования команд, а не повторного назначения в независимых настройках.

</details>

## Что можно добавить после проверки

Для каждой зоны можно отдельно учесть [темноту, шум или ручное управление](/ru/docs/automations/lighting/recipes/single-zone/). Добавляйте по одному условию и проверяйте все затронутые группы.

Для общего действия «выключить всё» нужна отдельная настройка: простое переключение нескольких групп может выключить горящие, но включить погашенные.
