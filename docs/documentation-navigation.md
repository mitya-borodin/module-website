# Возврат из документации на сайт

Решение автора и проверка: **9 октября 2026 года**. Из любой статьи и с начала документации
должны быть видны переходы на главную инженерной услуги и страницу ПО. Ранее такие ссылки
находились только в группе «Сайт» бокового меню.

## Реализация

- [docs-header.astro](../src/components/docs-header.astro) оборачивает штатный Header Starlight
  и добавляет постоянную строку «Главная» → `/`, «ПО Ritmod» → `/software/`.
- Подключение общего Header — в [astro.config.mjs](../astro.config.mjs). Ссылки работают при
  прямом открытии статьи и не зависят от истории браузера или JavaScript.
- Размер шапки, отступ содержимого и положение мобильного меню согласованы через переменные
  Starlight в [docs.css](../src/styles/docs.css). Поиск, выбор темы и переход по названию
  к началу документации сохранены; оформление статей не менялось.

## Проверка

`yarn build` (включая `astro check`) — успешно, 0 errors/warnings/hints. В собранных HTML всех
11 страниц документации есть обе ссылки; целевые страницы существуют. Redirect-страницы
проверкой общей шапки не охватываются — они переводят на актуальную статью.

В локальном браузере проверены 320×740, 375×812, 768×900, 800×900 и 1280×720: ссылки видны,
горизонтального переполнения нет. На телефоне меню открывается под шапкой и закрывается по Escape.
Оба перехода проверены нажатием, доступ с клавиатуры сохраняет видимый focus. Начало документации
также использует новую шапку.
