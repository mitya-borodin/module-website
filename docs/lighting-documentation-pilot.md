## Scope и владельцы

Реализованы восемь страниц в `src/content/docs/ru/docs/automations/lighting/`, обновлён вход
`/ru/docs/`, добавлена боковая навигация и адресная ссылка с карточки освещения на `/software/`.
Заголовки статей получили отдельный читаемый размер; стиль вводного hero сохранён.
Для мобильного меню добавлен узкий adapter: встроенный Starlight менял `aria-expanded` контейнера,
но не кнопки. Adapter синхронизирует объявляемое состояние кнопки, сохраняя штатное управление.
Не менялись backend, webapp, runtime, схемы, зависимости, домен, indexing policy или deployment.

Это **авторская редакция для review**, не автоматическая выгрузка всех 123 annotation nodes.
Описание доступных настроек и диагностических групп написано по источнику; оно не является новым
доменным контрактом. Текущие имена из Module сохранены для сопоставления, пользовательские
объяснения не объявлены уже внедрёнными backend annotations.

## Незакрытые следующие шаги

- Редакционная приёмка автором: ясность, полнота, терминология и желаемая глубина.
- Canonical rewrite annotations и автоматический versioned export — отдельная backend-задача.
  До неё справочник не называть автоматически синхронизируемым; изменение поведения требует
  повторной сверки проекции. После экспорта заменить ручные справочные фрагменты его consumer-ом,
  оставив задачи пользователя и рецепты авторскими страницами.
- Полный прогон создания/сохранения в GUI, совместных сценариев и аппаратных outcomes отдельно.
  Навигация первой настройки сверена в текущем GUI; граница проверки описана ниже.
- Подробный рецепт календарных профилей, действия по времени вместе с force, общий OFF и связи
  разных типов макросов не объявлены выполненными.
- Публичное размещение, `site`/sitemap и снятие `noindex,nofollow` не разрешены этой задачей.

## Вход по уровню погружения

По отзыву автора от 30 сентября порядок чтения применён к `/ru/docs/` и боковому меню.
Владелец решения — [research brief](../../module-market-intelligence/internet-promotion/spec/lighting-documentation-pilot.md#правило-новой-редакции).

- Основная кнопка ведёт сразу в первую настройку света по движению, а не в обзор понятий.
- Сначала показаны первая настройка и готовые сценарии, затем — примеры нескольких зон.
- Практическая проверка неполадки доступна без раскрытия справочника.
- Ссылки на обзор, устройства и параметры находятся ниже, в закрытом блоке. Справочная группа
  меню также закрыта по умолчанию; текущая справочная статья может раскрыть её штатным поведением Starlight.
- Порядок «предыдущая/следующая» следует новому меню: начало → первая настройка → сценарии.

Изменены только входной MDX и sidebar в `astro.config.mjs`. Тексты восьми статей, CSS, компоненты,
макросы, зависимости, публикация и indexing policy в этом срезе не менялись.

Проверки: `yarn build` успешен (Astro check: 0 errors/warnings/hints); 460 внутренних ссылок/якорей
из девяти страниц документации и страницы ПО — без ошибок, один H1 и `noindex` сохранены.
В браузере просмотрены вход на 320/390/1440 px, закрытый и открытый справочник на 320 px,
настольный sidebar и открытое мобильное меню на 390 px. Общего горизонтального overflow нет.
Enter/Space открывают/закрывают пояснение, Enter/Escape — мобильное меню с возвратом фокуса.
Существующие сообщения сборки о docs entry 404 и незаданном `site`/sitemap не относятся к этой правке.
