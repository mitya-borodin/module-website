## Подтверждённая текущая логика

Source review: `module-automation@ed9b11de`, 8 октября 2026 года.
Это чтение исходников, без прогона backend tests, управления GUI и испытаний газа.
При финальной проверке HEAD backend был `80c78132`: diff от `ed9b11de` не затрагивает
`leaks`, `positional-drive` и их owners, поэтому source evidence сохраняет силу в этом scope.
Главный owner — [Leaks Current Behavior](../../module-automation/src/domain/macros/docs/owners/leaks.md).
Версия `LEAKS v1` использует `POSITION_DRIVER v0`.

| Утверждение | Источник и предел |
| --- | --- |
| Готовый alarm либо числовой вход, несколько датчиков по OR | [Сбор входов](../../module-automation/src/domain/macros/leaks/1-leaks-collect-data.ts): SWITCH/on, ENUM/exact literal, VALUE/strict greater; missing control даёт false |
| Нет универсальной шкалы концентрации | [Settings](../../module-automation/src/domain/macros/leaks/0.1-leaks-settings.ts): числовой threshold без конвертации единиц, не опубликован как безопасное значение для газа |
| Команда CLOSE по тревоге | [Sensor stage](../../module-automation/src/domain/macros/leaks/4-leaks-sensor-base-computation.ts): после warm-up, при guards target и driver |
| Автоматическое OPEN при отсутствии тревоги | Та же sensor stage, после истечения [open block](../../module-automation/src/domain/macros/leaks/1.1-leaks-blocks.ts); нет отдельного gas-mode или обязательного ручного подтверждения |
| Force не является защитной блокировкой | [Priority](../../module-automation/src/domain/macros/leaks/2-leaks-priority-computation.ts): OPEN может пройти до sensor stage; после terminal state регулярная логика продолжается |
| Команда не доказывает физическое перекрытие | [Virtual output](../../module-automation/src/domain/macros/leaks/0.6-leaks-hardware-output.ts), [driver owner](../../module-automation/src/domain/macros/docs/owners/positional-drive.md): совместимость, доставка, привод и feedback требуют проверки |
| Недоступность и старт не равны готовности | [State access](../../module-automation/src/domain/macros/leaks/0.5-leaks-state-access.ts): ожидание данных всех driver roles и готовности; leak collection не реализует самостоятельную fail-closed обработку отсутствия датчиков |

Известные незакрытые проблемы target guard, missing input, restore/output и отдельных drive outputs
не исправлены. Никакая модель газового датчика или клапана не квалифицирована этим проходом.

## Редакционный вывод и граница безопасности

Из source следует, что простое копирование водяного сценария в обещание самостоятельной газовой
защиты было бы необоснованным: автоматическое OPEN может вернуть подачу без устранения причины.
Это инженерный вывод, а не новый обязательный норматив или результат аппаратных испытаний.

Страница начинает с результата и механики, но сразу открыто сообщает эту границу.
Удержание закрытого газового клапана до разрешённого восстановления описано как **требование
к отдельному защитному решению**, а не действующая функция Module.
Совместимость такого решения с Module не подтверждена. Ручная команда из приложения не заявлена
способом обхода защитной блокировки. Самостоятельные пользовательские испытания выпуском газа
или пламенем не предлагаются.

Для будущего обещания готового решения нужны: профильный выбор и квалификация оборудования;
подтверждённое перекрытие; отсутствие нежелательного OPEN после снятия тревоги, force или
перезапуска; проверка потери связи/питания; согласованный порядок восстановления.
Если эти требования потребуют изменения runtime, целевой репозиторий — `module-automation`;
поручение на такое изменение в текущую задачу не входит.

## Внешние источники

Проверены 8 октября 2026 года. Их роль — общие правила обращения с газом и пример класса
оборудования; они не доказывают совместимость с Module и не заменяют проект для конкретного дома.

- [МОСГАЗ: действия при запахе газа](https://www.mos-gaz.ru/individuals/info/accident) — прочитана
  официальная страница: не переключать электрические приборы, выйти, позвонить 104 вне помещения;
  указан также 112, запрещено обнаружение утечки пламенем.
- [МОСГАЗ: правила пользования](https://www.mos-gaz.ru/individuals/info/pravila-polzovaniya-gazom-v-bytu) —
  прочитана официальная страница: самостоятельные установка, замена и ремонт газового оборудования
  не допускаются; неисправности требуют специалиста.
- [Seitron SEGUGIO plus, руководство](https://seitron.com/media/download/manuali/sicurezza_gas/domestico/044256_RGDGPLMP1RSE_FIS_ENG.pdf) —
  проиндексированный фрагмент первичного PDF: исполнения methane/LPG, зависимость размещения от
  типа газа, схемы с manual-reset valves. Прямое открытие PDF инструментом вернуло 403:
  полного чтения руководства не заявлено. Числовые уровни, высоты монтажа и схема подключения
  на сайт не перенесены.
- [Seitron Beagle LPG kit](https://www.seitron.com/en/product/beagle-lpg-gas-leak-detector-kit/) —
  проиндексированная карточка производителя сообщает о клапане с ручным восстановлением; прямое
  открытие также 403. Использовано только как evidence существования такого класса, без
  рекомендации модели, сертификации решения Module или утверждения нормативной универсальности.
