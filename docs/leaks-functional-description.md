## Существенные ограничения

На странице явно сохранены автоматическое открытие и точка отсчёта паузы, отсутствие обязательного
ручного подтверждения, приоритет принудительного открытия и отсутствие обещания удерживать ручное
состояние. Датчик контролирует место контакта с водой; кран перекрывает только свой участок.
Подача команды не выдается за установленный факт прекращения воды.

Current owner содержит незакрытые проблемы: target-state guard может не повторить CLOSE при
несовпадении target и реального привода; missing inputs могут дать no-leak; readiness зависит от
полной группы controls; присутствуют риски отложенных output и restore. У positional-drive есть
ограничения отдельных output families, включая enum-only OPEN/CLOSE. Они здесь не исправлены.
Страница требует проверки всей выбранной связки, перезапуска и недоступности устройств; описание
не является аппаратной приёмкой или квалификацией любого привода.

Не добавлены обещания постоянной ручной блокировки до подтверждения, автономного резервирования
питания, сообщений на телефон, автоматического ремонта, остановки насоса или гарантии от любого
затопления. Для обещания конкретного готового решения остаётся объектная проверка сенсор → команда
→ физическое перекрытие → восстановление с учётом этих ограничений.
