## Состав и источники поведения

Одна прихожая без окон: настенный PIR-датчик, две кнопки без фиксации, два светильника на одном
релейном выходе. Автоматика Wiren Board, питание MEAN WELL, модульная автоматическая защита EKF.
По решению автора 10.10.2026 это объясняющий слой документации: цены, смета,
модель корпуса и размерные таблицы удалены с публичной страницы и из рисунка.
Собранные данные сохранены в [архиве размерного варианта](archive/2026-10-10-hallway-dimensional-study.md)
для дальнейшей инженерной комплектации журнала. Это не готовый комплект к заказу.

После ревью автора основной путь визуальный: размещение → монтажная компоновка со слоями → десять
шагов с адаптивной последовательностью кадров GUI → проверка. Роли приборов, полный перечень соединений и расширенная справка
сохранены в закрытых раскрытиях; обязательные действия и значения остаются рядом с кадрами.
Общие требования к изображениям — в
[research visual owner](../../module-market-intelligence/internet-promotion/spec/automation-illustration-style.md).
PIR отмечен красным сектором и лучами; для радара принят голубой сектор с волнами. Сектор
концептуальный: не выдаётся за измеренную диаграмму и не гарантирует покрытие всего помещения.

Поведение и подписи сверены с актуальными локальными источниками:

  `src/domain/macros/lighting/0.1-lighting-settings.ts`,

  `4-lighting-sensor-base-computation.ts`,
  `src/domain/macros/macros/0.5-macros-switch-computation.ts`.
- GUI `module-automation-webapp`, HEAD `ab412edb`: навигация `MainLayout`, редактор

- [Архив прежней инструкции](archive/2026-10-08-documentation/src/content/docs/ru/docs/automations/lighting/setup.mdx)
  использован только как контекст пути; прежние кадры не выданы за новую настройку.

Управление кнопками — дискретные входы с переходом UP; прямое управление реле в самом модуле
