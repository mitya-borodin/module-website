## Контекст и путь читателя

После замечания автора об абстрактности первая редакция перестроена вокруг освещения прихожей.
Сначала даны исходные условия, каналы устройств, различие типа и экземпляра макроса,
настроек, состояния и наблюдаемых значений. Далее один пример проходит через приём события,
очередь, расчёт, SEND, обратное наблюдение и публикацию состояния. Перед каждой схемой есть
маршрут чтения. Пять закрытых раскрытий сохраняют точные API, алгоритмы и ошибки.
Основной текст читается при закрытых раскрытиях. Имена классов служат привязкой к схемам.

Принцип сопровождения закреплён у
[владельца публичной подачи](../../module-market-intelligence/internet-promotion/spec/user-documentation-rules.md#контекст-инженерного-объяснения).
