# module-website

Публичный сайт Module.

## Команды

```sh
yarn install --frozen-lockfile
yarn dev
yarn build
```

Первый рабочий срез — адаптивная русская главная. Сайт находится на стадии непубличного прототипа:
форма обращения, живое GUI-доказательство, домен и production deployment ещё не подключены.

Документация подключена через Starlight и доступна по `/ru/docs/`. Сейчас опубликована только
стартовая страница и навигационный каркас; содержательные разделы добавляются после отдельной
редакционной подготовки.
