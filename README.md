# module-website

Публичный сайт Ritmod.

## Команды

```sh
yarn install --frozen-lockfile
yarn dev
yarn build
```

Текущий срез проверен 15 октября 2026 года: сайт — адаптивная русская главная с общим результатом
«проект, щит, ПО и сценарии, документация» и отдельная страница `/software/` о ПО Ritmod.
Главная описывает подготовку и доставку комплекта для разных объектов, не только частных домов.
Монтаж и пусконаладка не включены в обещание автоматически.

Сайт сохраняет `noindex,nofollow`; форма обращения не подключена. Docker, CI и подключение
`ritmod.ru` описаны в [контракте деплоя](docs/deployment.md). Публичный HTTPS доступен:
15.10.2026 проверены 14 содержательных страниц, их canonical, Open Graph и изображения.
HTTP и `www` переходят на `https://ritmod.ru/`. Успешный конкретный CI run и SHA
развёрнутого образа этой проверкой не установлены. По предоставленным владельцем контактам добавлены email, Telegram, телефон,
WhatsApp и прямая ссылка на профиль MAX, локально считанная из его QR-кода. Иллюстрация комплекта не является
фото поставки или скриншотом интерфейса.
Трёхлетний опыт применения автоматизаций указан по свидетельству владельца продукта, без
обещаний безотказности или утверждения срока эксплуатации каждой версии.

Содержательная основа и источники: [brief реализации](../module-market-intelligence/internet-promotion/spec/website-refresh-2026-09.md).

Документация подключена через Starlight и доступна по `/ru/docs/`. Опубликованы обзор, десять
функциональных описаний автоматизаций и [инструкция прихожей](docs/hallway-lighting-solution.md).
Входы в инструкцию есть на странице ПО и в описании освещения. GUI-путь прихожей
проверен частично: кадры физических кнопок/UP и полный запуск на оборудовании остаются открытыми.
Функциональные описания не подтверждают аппаратную приёмку всех сценариев.

Текущий HTTP-срез и границы запуска поиска — у
[владельца web-контракта](../module-market-intelligence/internet-promotion/spec/public-web-contract.md#проверка-публичного-сайта-15-октября-2026).
`robots.txt`, `sitemap.xml` и `llms.txt` отвечают `404`; поисковый запуск не завершён.
